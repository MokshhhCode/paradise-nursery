# Paradise Nursery

Paradise Nursery is a responsive plant shop demo built with React, Redux Toolkit, and Vite. Browse indoor plants by category, add plants to your cart, adjust quantities, and review your order total.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.

## Project files

- `src/AboutUs.jsx` — company story and values
- `src/App.css` — responsive visual styles and landing background
- `src/App.jsx` — landing, shop, and cart views with navigation
- `src/CartSlice.jsx` — Redux Toolkit cart state and actions
- `src/ProductList.jsx` — plant catalog and add-to-cart controls
- `src/CartItem.jsx` — cart rows, quantity controls, totals, and checkout

Plant photography is loaded from Unsplash and requires an internet connection.
